Aseprite 中文字体主题合集
==========================

包含主题
--------
1. aseprite-theme-cn-1.1.0.aseprite-extension —— Aseprite-CN 中文清晰字体主题（推荐）
   - 基于官方默认主题 1.3.18.5
   - 英文/数字保留官方像素字体，中文使用微软雅黑（Windows）并开启抗锯齿
   - 明暗双皮肤：cn-clear（浅色）/ cn-clear-dark（深色）
   - 彻底解决中文界面显示模糊问题

2. aseprite-theme-pixel.aseprite-extension —— 像素风中文主题（复古方案）
   - 整套 UI 使用 Zfull-GB 像素中文字体
   - 复古像素风观感，与像素画风格统一

安装方法（任选其一）
--------------------
方法一：双击 .aseprite-extension 文件，Aseprite 弹窗后点击 Install
方法二：Aseprite 菜单 Edit > Preferences > Extensions > Add Extensions
        选择对应文件安装
方法三：直接运行仓库根目录的 一键汉化.bat（同时安装汉化并自动配置）

切换主题
--------
安装后进入 Edit > Preferences > Theme 选择：
  - Aseprite-CN（浅色）       —— 对应主题 ID: cn-clear
  - Aseprite-CN Dark（深色）  —— 对应主题 ID: cn-clear-dark
  - Pixel                     —— 像素主题
